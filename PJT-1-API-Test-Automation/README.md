# 💰 PJT 1: 개발 서버 없이, '결제 보안 로직' 미리 검증하기

## 1. 왜 만들었나요? (Why)
보통 QA는 개발자가 서버를 완성해 줄 때까지 기다려야 합니다.
하지만 **"결제 권한(보안) 로직"**처럼 치명적인 기능은 마냥 기다릴 수 없다고 판단했습니다.

그래서 **Postman으로 '가짜 서버(Mock Server)'를 직접 만들고**, 기획서에 적힌 보안 규칙대로 시스템이 잘 방어하는지 **파이썬으로 먼저 시뮬레이션** 해본 프로젝트입니다.

## 2. 무엇을 확인했나요? (Checklist)
복잡한 기능보다는, 사고가 터지면 안 되는 **"핵심 방어 로직 2가지"**에 집중했습니다.

* **Case 1 (정상 승인):** "고객이 정상적인 경로로 결제하면, 200 OK(성공)가 뜨는가?"
* **Case 2 (보안 방어):** "권한 없는 사용자(해커)가 주소만 알고 접근했을 때, 403(차단)으로 잘 막아내는가?"

## 3. 사용한 도구 (Tools)
* **Postman Mock Server:** 아직 없는 개발 서버를 대신하기 위해 사용
* **Python (Requests):** 매번 손으로 클릭해서 확인하는 게 비효율적이라, 코드로 자동 확인
