## 📂 Projects (핵심 역량)

### 1️⃣ [PJT-1] 결제 보안 로직 검증 시뮬레이션
* **Target:** Postman Mock Server (가상 결제 서버)
* **Goal:** 개발 서버 없이도 **보안 정책(403 Forbidden)**과 **정상 승인(200 OK)** 로직을 선제적으로 검증
* **Tech:** Python, Requests, API Automation
* 👉 [프로젝트 바로가기](./PJT-1-API-Test-Automation)

### 2️⃣ [PJT-2] 자동차보험료 산출 & 상충 특약 방어
* **Target:** 복잡한 자동차보험 약관 및 할인/할증 로직
* **Goal:** 엑셀로 검증하던 수만 가지 경우의 수를 **Pytest로 자동화**하여 휴먼 에러 제거
* **Tech:** Python, Pytest, Data-Driven Testing
* 👉 [프로젝트 바로가기](./PJT-2-auto-insurance-calc)
